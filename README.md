# Fractal Design Lab 01

## Project Description

This project is a creative fractal-based visual design created for BS Computer Science Design Lab 01. The project demonstrates recursion, mathematical patterns, iteration, and creative visual design using Python.

## Fractal Type

* Fractal Mandel brot set

## Tools and Technologies

* Python
* NumPy
* Matplotlib
* Pillow (PIL)

## Features

* Recursive fractal generation
* Custom colors and visual effects
* Mathematical structure and symmetry
* High-resolution graphical output

## Setup and Run Instructions

1. Install Python 3.x.
2. Install the required libraries:

```bash
pip install numpy matplotlib pillow
```

3. Download or clone this repository.
4. Run the Python program:

```bash
python fractal_design.py
```

5. The program will generate the fractal design and save/display the output.
